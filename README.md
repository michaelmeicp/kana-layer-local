# Kana Layer｜假名讀本
v1.0.0 · 原創繁體中文介面及練習。貼上日文、切換讀音、為選取的漢字標音，或用八張題卡複習錯題。

## 開始
需要 Python 3 與現代瀏覽器。下載整個專案，在此目錄執行 `python3 -m http.server 8080 --bind 127.0.0.1`，開啟 http://127.0.0.1:8080 。只透過本機服務載入靜態檔案，不需要網際網路、帳號或金鑰。不要用 file:// 開啟 ES 模組。開發測試使用 Node.js 22：`npm test`、`node --check app.mjs`，不需安裝套件。CI 在推送後執行相同檢查。

## 閱讀方法
點「原文與手動標音」貼上草稿並套用；於原文框選連續漢字，再輸入假名讀音。相同漢字在不同位置分別標註。改動並套用原文會確認清除既有標音，取消時保留原狀。三種字體大小、晨光及夜讀模式、提示可切換；不提供 OCR、音訊、翻譯、辭典或自動詞界分析。假名僅依拼寫轉寫，不分辨助詞讀音或驗證人工漢字讀音是否符合語境。長音符及相連的 o＋う／お 用長音符號；えい保留 ei。詞界僅尊重原有空白、標點及非假名。未知文字保留。

練習核對拼音，部分長音亦接受未加符號的展開拼法。答錯或揭曉會加入錯題，答對移除。只記錄錯題 ID，不記錄作答歷史。

## 資料與架構
- index.html / style.css / app.mjs：本機互動與閱讀呈現，全頁使用系統字型；不含追蹤或第三方素材。
- parser.mjs：保留來源索引的假名轉寫；state.mjs：原文、標音、偏好、題卡、備份驗證及資料上下限。*.test.mjs：Node 內建測試。
- 已套用內容儲存於此瀏覽器與來源的 localStorage；未套用草稿不會寫入備份或跨重新載入保留。清除瀏覽資料或私人模式可能使紀錄遺失。選擇備份後先預覽，再確認取代；內容包含完整原文，請妥善保管。
